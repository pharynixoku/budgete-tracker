# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application designed to help users keep track of their expenses.

The application allows users to enter an expense name, amount, and category. The project is designed as a beginner-friendly project for practicing HTML and CSS.

## Features

The current version of the project includes:

- A main heading
- A short description
- Expense name input
- Amount input
- Category input
- Expense list section
- Responsive design for mobile devices
- Clean and simple user interface

## Technologies Used

This project uses:

- HTML5
- CSS3
